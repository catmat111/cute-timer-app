# 🌿 Matcha Garden

> **Um refúgio digital para a tua produtividade.**

O **Matcha Garden** é uma aplicação desktop minimalista desenhada para transformar a tua rotina de trabalho num ritual calmo e focado. Construído com uma stack moderna e performante, este projeto une a eficiência do **Rust** à flexibilidade do **React**.

### 🔒 Privacidade em Primeiro Lugar
Todos os teus dados (tarefas, configurações e links) são guardados localmente através de `localStorage`. **Nada sai do teu computador.**
---

## 🛠️ Stack Tecnológica

Este projeto foi desenvolvido como parte do meu percurso em **Engenharia Informática** no **IPT**, focando-me em performance e experiência de utilizador:

*   **Framework**: [Tauri](https://tauri.app/) (Desktop Nativo)
*   **Frontend**: React + TypeScript
*   **Estilização & Animações**: CSS3 + Framer Motion
*   **Ícones**: Lucide React

---

## 🚀 Como Utilizar

Se queres apenas usar a aplicação sem configurar o ambiente de desenvolvimento:

1.  Vai à secção de [**Releases**](https://github.com/catmat111/cute-timer-app/releases).
2.  Descarrega o instalador `.msi` mais recente.
3.  Instala e começa o teu ritual de foco. 🍵
